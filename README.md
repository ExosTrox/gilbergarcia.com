# Gilber Garcia

Personal portfolio and blog website with modern design and blog functionality.

## Features

- ✨ Modern, elegant design with animations
- 📝 Blog with full article viewer
- 🎨 Beautiful typography and gradients
- ⚡ Fast loading and responsive
- 🌐 Works on GitHub Pages

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Vite (development)
- GitHub Pages (hosting)

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Deployment

Site automatically deploys to GitHub Pages when pushing to main branch.
